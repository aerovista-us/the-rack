Publish by editing one JSON file

  1. Put PNG pages in content/your-book/pages/.
  2. Put optional MP4/WebM clips in content/your-book/video/.
  3. Add the book and reading sequence to rack.json.
  4. Serve the folder over HTTP. A tiny local server command is included in the README.
{
  "type": "video",
  "src": "content/book/video/moment-01.mp4",
  "poster": "content/book/pages/004.png",
  "caption": "A moment between pages",
  "autoplay": false
}
